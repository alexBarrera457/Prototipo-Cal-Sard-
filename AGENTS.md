# Cal Sardà - Agent Guidelines

## Tech Stack
- Framework: Angular 22 (Standalone components)
- Test Runner: Vitest (`ng test`)
- Language: TypeScript
- Formatting: Prettier

## Development Workflows
- **Test-Driven Development**: When implementing features or bug fixes, follow the `tdd` skill (red -> green) using vertical slices.
- **Grilling & Architecture**: Use `/grill-me` or `grilling` to align on designs before coding.
- **Systematic Debugging**: Use `diagnosing-bugs` for isolating and reproducing issues with regression tests.

## Agent Skills
Skills are installed locally in `.agents/skills/`.
