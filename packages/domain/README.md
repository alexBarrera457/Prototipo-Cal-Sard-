# @cal-sarda/domain

Modelos de dominio compartidos y contratos TypeScript para la aplicación y servicios de **Cal Sardà**.

## Exportaciones
- `Category`: Interfaz de categoría del catálogo.
- `Product`: Interfaz del producto gourmet.
- `CartItem`: Elemento dentro del carrito de compra.
- `Order`: Modelo de pedido y cliente.
